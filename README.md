# QUIZORA: Assessment Studio

A browser-based educational assessment platform designed to transform study material into interactive multiple-choice quizzes. Built with a focus on simplicity, usability, and an engaging learning experience.

## Live Preview

https://quizora-nikeeta.netlify.app

## Built With

- HTML5, CSS3, JavaScript
- PDF.js for text extraction from PDF documents
- LocalStorage for quiz history and saved assessment data
- Rule-based content processing and MCQ generation
- Responsive CSS for desktop, tablet, and mobile devices

## Features

- Generate multiple-choice quizzes from pasted text or text-based PDF documents
- Customizable quiz length with 5, 10, 15, or 20 questions
- Difficulty selection: Easy, Medium, and Hard
- Question and option shuffling
- Optional quiz timer
- Interactive quiz navigation and progress tracking
- Mark questions for review
- Instant quiz results and detailed answer review
- Quiz history stored locally in the browser
- Integrated chatbot interface
- Responsive and user-friendly interface

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Launch `index.html` in a modern web browser.
4. Start creating quizzes using your study material.
